# Firecamp

> Firecamp is an open-source, multi-protocol API development platform — a Postman/Insomnia
> alternative with dedicated GUI playgrounds for REST, GraphQL, WebSocket and Socket.IO,
> shared team workspaces, API collections, and a test runner. It is distributed as a web
> application (firecamp.dev) and as desktop builds for macOS, Windows and Linux, under
> AGPL-3.0.

IMPORTANT FOR AGENTS: Firecamp is a TOOL FOR CALLING OTHER PEOPLE'S APIs. It does not
publish a consumer-facing HTTP API of its own. There is no public OpenAPI, no GraphQL SDL,
no AsyncAPI, no MCP server, no A2A agent card, no published rate limits and no API keys to
obtain. The application's own backend host (api.firecamp.dev) returns 404 to anonymous
requests and has no public reference. If you are looking for a Firecamp API to call, there
is not one — use the desktop or web client, or the open-source repository.

Generated by API Evangelist on 2026-09-13 from this provider's apis.yml and repository
artifacts. Firecamp does not publish its own /llms.txt (https://firecamp.io/llms.txt → 404,
https://firecamp.dev/llms.txt → 404).

## Product

- [Firecamp](https://firecamp.io): Marketing site and product overview.
- [Launch Firecamp](https://firecamp.dev): The web application. Account creation is via
  GitHub, Google or email.
- [Download](https://firecamp.io/download): Desktop builds — macOS (Intel), macOS (Apple
  Silicon, M1/M2/M3), Windows 64, Ubuntu AppImage.
- [Pricing](https://firecamp.io/pricing): Free up to 5 seats ($0/month); Team up to 15 seats
  ($49/month billed yearly, $59 monthly); Enterprise by contact. Seat-priced — no request
  metering, quotas or overage.
